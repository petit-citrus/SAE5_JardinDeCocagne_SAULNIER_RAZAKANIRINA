# SAÉ 5 — Jardins de Cocagne

Projet réalisé dans le cadre de la SAÉ 5 (BUT 3 Informatique, IUT de Saint-Dié-des-Vosges).

Logiciel de gestion commerciale pour le Réseau Cocagne : back office pour la gestion des Jardins (adhérents, abonnements, livraisons) et front office pour l'espace client.

## Équipe

- RAZAKANIRINA Aingo
- SAULNIER Simon

## Stack technique

- **Backend** : PHP / Symfony
- **Moteur de templates** : Twig (+ React pour certains composants interactifs)
- **Base de données** : PostgreSQL
- **Carte** : Leaflet + OpenStreetMap
- **Itinéraire / tournées** : Leaflet Routing Machine + OSRM
- **Calendrier** : php-rrule + services métier Symfony
